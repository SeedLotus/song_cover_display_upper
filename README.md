## 本 Fork 的迭代优化

上游原版的已知问题（B站切换双下落/新旧封面闪烁、快速切换掉初始化、后台久挂不响应拨臂、拔出后不会自动重连）在本 Fork 中**已全部修复**，并完成了大量上游未覆盖的稳定性与体验优化。完整技术细节见 [DEV_LOG.md](./DEV_LOG.md)。

### 通信与传输可靠性

- **串口帧解析重构**：按 `\n` 分帧，消除断包/粘包/误匹配（原版用 `Contains` 解析原始字节流）
- **图片传输状态机**：`Idle → Starting → Transferring → AwaitingAck` 串行化传输，封面快速切换不再并发冲突、不再掉初始化
- **丢包重传**：实现 `/r` `/x` 重传响应（原版未实现）
- **分包数对齐固件**：修正 1889/1888 包越界问题
- **USB 插拔自动重连**：WMI 设备事件监听 + 重连握手序列（稳定期、缓冲区清理、线路安静检测、长重试）
- **传输取消死锁修复**：跨会话快速切换（PotPlayer↔B站）不再锁死封面流水线

### SMTC 事件处理（Windows 媒体控制）

- **事件滞后治理**：SMTC `MediaPropertiesChanged` 触发瞬间属性可能仍是上一个媒体，两段式主动拉取（120ms + 500ms 确认）修复"封面卡在上一个视频"
- **感知哈希去重**：aHash 感知哈希判定封面变体——同一歌曲的不同分辨率/编码缩略图（网易云播放/暂停会推送）不再触发重传；同专辑连播也不再重复传输
- **会话抖动防抖**：网易云播放/暂停会重建 SMTC 会话并报出 50ms 级过时状态抖动，自适应防抖只下发最终稳定状态（安静期真实操作 0 延迟即时响应）
- **媒体身份去重**：播放/暂停不再重复触发封面处理

### 下位机协同（播放/转动状态）

- **believed-state 模型**：上位机跟踪下位机播放状态，只在不一致时下发指令，避免重复指令干扰摇臂状态机
- **转动恢复机制**：固件 `/t` 会停转且仅 `/1` 能恢复——切歌全程 Playing 的播放器（如网易云）下原版转盘永久停转；本 Fork 在传输结束后无条件补发状态恢复转动
- **固件语义主动探测**：界面一键探测设备固件 `/1` `/0` 语义（设态/翻转），结果持久化，探测为设态即启用转动恢复
- **协议 v2 前瞻支持**：连接时 `/v` 版本协商，配套新固件自动启用幂等设态指令（彻底消除丢包失同步）

### 延迟优化（相对原版实测）

| 场景 | 原版/早期版本 | 本 Fork |
|------|------|------|
| 播放/暂停摇臂响应 | ~1s（定时器轮询） | **≈0ms**（事件即时下发） |
| 切歌封面出现 | >2s | **~0.55s** |
| 切歌后旋转恢复 | 不恢复（网易云必现停转） | **~1.2s 自动恢复** |
| 图片编码/发送 | UI 线程阻塞 | 后台编码 + 16 包批量发送 |

### 体验与工程

- **托盘化**：最小化到托盘、双击呼出、右键菜单含「开机自启动」「静默启动」开关
- **静默启动**：可选设置，启动不弹窗仅驻托盘；自启快捷方式自动携带 `--silent`
- **单实例 + IPC**：重复启动通知已有实例弹窗
- **文件诊断日志**：exe 同目录 `logs/` 滚动日志（保留 7 天），实机问题可回溯
- **退出资源清理**：托盘图标/串口/媒体会话句柄全部正确释放
- **编译零警告**：修复全部 nullable 与编译警告

## 上下位通信协议

上位机命令以 `/` 开头，`\n` 结尾：

| 命令 | 功能 | 说明 |
| - | - | - |
| `/1` | 要求下位机播放 | 图像开始旋转，唱臂靠近胶片 |
| `/0` | 要求下位机暂停 | 图像暂停旋转，唱臂离开胶片 |
| `/t` | 上位机将要传送图片 | 下位机暂停旋转、清零丢包计数、回复 `/k` |
| `/o` | 图片发送完毕 | 下位机统计丢包，无丢包则播放下落动画并回复 `/a` |
| `/h` | 心跳（协议 v2 固件） | 仅刷新休眠计时，不改变播放状态与显示；旧固件忽略 |
| `/v` | 协议版本查询（协议 v2 固件） | v2 固件回复 `/v2`（`/1` `/0` 为幂等设态）；旧固件忽略 |

图片包：以 `#` 开头，后接 2 字节大端包序号 + 61 字节 RGB565 数据，单张 240×240 封面固定 1888 包。

下位机上行命令：`/q1` `/q0`（拨臂请求播放/暂停）、`/k`（收图就绪）、`/a`（接收完成）、`/r[n]` `/x[n]`（重传请求）、`/ec` `/el`（唱臂驱动失败报告）、`/v2`（协议版本应答）。

**休眠**：下位机 60 秒无命令进入休眠。协议 v2 固件下上位机状态稳定时每秒发 `/h` 保活；配旧固件时 `/h` 被忽略，仍可能休眠，建议升级固件。

> 注意：旧固件（v1）的 `/k` `/a` 回复在 TX 忙时会丢失（本 Fork 上位机已全部兼容，不依赖其到达）；彻底修复需烧录[配套固件仓库](https://github.com/SeedLotus/song_cover_display)的新固件。

## 平台限制

依赖 WPF 与 Windows SMTC，仅支持 Win10/Win11。设备 `vid/pid` 为 `2E3C/2568`，USB CDC 虚拟串口（波特率配置无意义，实际为全速 USB 12Mbps）。其他平台的移植指引请参考原仓库 README。
